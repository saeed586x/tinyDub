tinyDub — Windows build/install

Developer build prerequisites:
- Visual Studio 2022 with Desktop development with C++
- Windows 10/11 SDK
- CMake 3.24+

Build from Developer PowerShell for VS 2022:
  cmake -S . -B build -G "Visual Studio 17 2022" -A x64
  cmake --build build --config Release --parallel

Or:
  powershell -ExecutionPolicy Bypass -File .\scripts\build-install.ps1

The executable is build\Release\tinyDub.exe.

For end users, use the CI artifact generated by GitHub Actions instead of installing CMake or Visual Studio.

API key:
  $env:GEMINI_API_KEY = "YOUR_KEY"
  .\build\Release\tinyDub.exe

The application stores a key entered through the UI with Windows DPAPI.
